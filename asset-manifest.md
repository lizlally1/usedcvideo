## Fonts — `public/fonts/`

| File | Role |
|---|---|
| `oswald-variable-latin.woff2` | Display font (titles, dates, large numerals) — loaded via `src/styles/loadFonts.ts` |
| `inter-variable-latin.woff2` | Body font (supporting text, captions, lower-third support lines) — loaded via `src/styles/loadFonts.ts` |

Both are variable fonts (weight range in one file) downloaded once from
Google Fonts and bundled locally so rendering never depends on network
access — see `render-notes.md` for why.

## Logos — `public/logos/`

No separate logo image file was provided with the uploaded footage. Rather
than fabricate a logo mark, the brand wordmark is rendered as a typographic
lockup in `src/components/Logo.tsx`, styled after the company's own
branded signage visible on-camera in `hq-reception-reveal.mp4`. This
directory is kept empty/reserved in case an official logo file is supplied
later — drop an SVG/PNG here and update `Logo.tsx` to use it via
`<SafeImage>` instead of the text lockup.
